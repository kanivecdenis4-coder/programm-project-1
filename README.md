# Програмний проєкт 1. Задача 3

**Тема:** Засоби функціонального програмування мови C++. Анонімні функції та функціональні об'єкти. Three-way comparison.

**Виконавець:** Канівець Денис , група К-27

## 1. Умова задачі

Написати клас функціональних об'єктів. Об'єкт класу ініціалізується послідовністю різних цілих чисел та їх частот.
Оператор `()` повертає випадкове число з цієї послідовності, щоб частота його отримання відповідала заданій.

Приклад: на вхід дають числа 1, 2, 3 та частоти 1, 2, 2. Тоді із сукупності згенерованих чисел приблизно 1/5 має бути 1,
приблизно 2/5 має бути 2 і приблизно 2/5 має бути 3.

Програма зчитує з текстового файлу натуральне число, послідовність вхідних чисел та послідовність їх частот.
Далі вона перевіряє, наскільки добре працює бібліотека випадкових чисел: генерує числа і звіряє, чи дійсно реальні частоти
відповідають заданим. На виході виводяться вхідні числа, задані частоти, отримані частоти та найбільша розбіжність частот.

## 3. Компілятор та збірка

Компілятор: **MSVC (Microsoft Visual Studio)**, стандарт `/std:c++latest` (C++23).
Конфігурація: Debug, x64.

Збірка у Visual Studio: **Збірка → Зібрати рішення** (Build → Build Solution), запуск: **Налагодження → Запуск без налагодження** (Ctrl+F5).

Програма приймає необов'язкові аргументи командного рядка:

    Project1.exe [вхідний_файл] [вихідний_файл]

За замовчуванням використовуються `Input.txt` (вхід) та `output.txt` (вихід).

## 4. Формат вхідних даних

Текстовий файл, значення розділені пробілами або переносами рядків:

    n                 - натуральне число, кількість чисел
    a1 a2 ... an      - n різних цілих чисел
    f1 f2 ... fn      - n натуральних частот (fi - частота числа ai)

Приклад (`Input.txt`):

    3
    1 2 3
    1 2 2

Тут числа 1, 2, 3 мають частоти 1, 2, 2, тобто відносні частоти 1/5, 2/5, 2/5.

Обмеження: `n` від 1 до 1 000 000; усі числа `ai` різні; кожна частота `fi` - натуральне число.

## 5. Обробка помилок

Програма не завершується аварійно, а виводить повідомлення про помилку і повертає код 1 у таких випадках:

- вхідний файл неможливо відкрити або він порожній;
- значення не є цілим числом (наприклад, `1.5` або текст);
- `n` не є натуральним, або завелике;
- у файлі менше даних, ніж потрібно, або є зайві дані наприкінці;
- частота не є натуральним числом (нуль чи від'ємна);
- у послідовності є однакові числа;
- сума частот спричиняє переповнення;
- неможливо відкрити вихідний файл для запису.

## 6. Алгоритм

1. Зчитати та перевірити вхідний файл (`reader.hpp`).
2. Створити об'єкт `WeightedRandom` з числами та частотами. У конструкторі обчислюються накопичені частоти
   (`std::partial_sum` з `std::plus<>`) та створюється рівномірний розподіл на відрізку `[1, сума частот]`.
3. При виклику `operator()` генерується випадкове число `r` з цього відрізка, і за допомогою бінарного пошуку
   (`std::ranges::lower_bound`) по накопичених частотах знаходиться відповідне число.
   Ймовірність вибору числа пропорційна його частоті.
4. Згенерувати 1 000 000 чисел та підрахувати, скільки разів зустрілось кожне.
5. Обчислити відносні частоти, розбіжність `|задана - отримана|` для кожного числа та найбільшу розбіжність.
6. Вивести результат на екран та записати у `output.txt`.
